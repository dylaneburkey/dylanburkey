CWRU Bearing Analysis

Description

Diagnosed bearing faults on 2 hp motor using CWRU vibration data in MATLAB (RMS, regression, Newton-Raphson); estimated speed within 0.3%.

Predicted bearing remaining useful life via numerical integration (RK4, Euler); validated failure prediction within 0.1 hrs of true failure time.
